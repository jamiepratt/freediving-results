# Private census evidence contract

`scripts/census_contract.py` validates and queries `census-evidence/v1` JSON snapshots for the owner evidence workspace in [issue #54](https://github.com/jamiepratt/freediving-results/issues/54). A snapshot has a dated scope and separate event, source, source-position, discovery-gap and relationship records. Source records retain original-byte hashes, acquisition and URL provenance, authority type, and selected-view state where applicable. Position records retain a source locator, printed raw fields or an explicit unresolved reason, and exact observation-version references. Relationships require a cited basis and an explicit evidence state. The summary always reports confirmed distinct sporting attempts as `null`; source positions and observation versions are separate counts.

Run `python3 scripts/census_contract.py validate SNAPSHOT.json` to check a private snapshot, or `python3 scripts/census_contract.py query --event EVENT_ID --source SOURCE_ID --status parsed SNAPSHOT.json` to select records. Query output retains gap and relationship records relevant to the selected positions. Neither command edits evidence or grants extraction validation, athlete identity approval, event selection or publication.

The 2026-09-28 baseline is privately retained in ignored `data/issue55-baseline-20260928/`. Its reproducible receipt has SHA-256 `360fc515fdd31e9c750b0c51e12092741b7d15e80cafb602288a76aba67b6ff6`; the three-position contract sample has SHA-256 `2ea2f682d00bbdeb904de26ab89b83dcf1217d2daca84d2ef58fd5e1e7127a36`. The 466-file worker bundle verified with index SHA-256 `cebc88ea6907170fa28058e1ba3e40f2c541938cf75047be08f5665ffa3d305c`. It is a bounded snapshot of retained evidence, not the complete 2025-2026 census. The worker and championship cohorts overlap and their source or row counts cannot be added into a unique-attempt total. The ongoing discovery and full row-level materialization remain tracked in [issue #55](https://github.com/jamiepratt/freediving-results/issues/55).

## Retained worker projection, 2026-09-28

`scripts/project_worker_positions.py` replays a retained worker bundle into a private `census-evidence/v1` JSON snapshot. It verifies every indexed file, imported source and artifact hash, and every database observation against its immutable artifact candidate. Run it with `python3 scripts/project_worker_positions.py BUNDLE_DIR IGNORED_OUTPUT.json --cutoff 2026-09-28T11:27:24Z`; it requires `pg_restore` and `bb`. Keep the output in an ignored private directory because it contains athlete results. Validate and query it with `scripts/census_contract.py` as above.

The replayed B45 bundle contains 107 acquisitions across 105 byte hashes. Its database has 91 imported jobs and 11,150 observation versions, each with an exact source position; 11,146 are parsed and four are unparsed. Sixteen retained source hashes have no imported extraction and carry explicit source gaps. Two more retained artifact jobs contain 136 candidates absent from the imported database; the snapshot reports them separately rather than counting them as imported versions. It also records repeated source hashes as overlap candidates, without asserting a same-attempt relationship. Only two exact dated events can be linked from the parsed fields. Other dates, sessions and categories remain null where the retained candidates do not establish them. Confirmed distinct attempts remain unknown; the output makes no global coverage claim. The championship B16 cohort and the remaining discovery work are outside this projection.

## B45 gap supplement

`scripts/reconcile_worker_gaps.py` joins the private B45 projection to an explicitly authored assessment JSON. Its two maps are `source_dispositions`, keyed by full 64-character source SHA-256, with `disposition`, `evidence` and `next_step`, and `row_dispositions`, keyed by full `source-position:` ID, with `disposition`, `failure_reason` and `next_step`. Both maps must cover exactly the 16 no-import source hashes and four unparsed imported positions. Run:

```sh
python3 scripts/reconcile_worker_gaps.py PROJECTION.json ASSESSMENT.json BUNDLE/payload BUNDLE_INDEX.json IGNORED_OUTPUT.json
```

The `worker-gap-reconciliation/v1` supplement preserves each complete source record and its acquisitions, verifies each gap's immutable object bytes against its hash and the projection's bundle index, and preserves each unparsed position's raw evidence, citation, job and artifact references. It records SHA-256 hashes of the exact input files, unchanged projection counts, parsed/unparsed/quarantined position counts, and the two retained-only artifact jobs with their 136 candidates separately. The output is deterministic for fixed inputs and remains private because it includes athlete results. A disposition is an evidence note; it does not approve a parser change, establish distinct attempts, or resolve the wider search-scope gap.
