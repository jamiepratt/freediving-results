# 2025 CMAS indoor JSON result ingestion

The 2025 Athens [CMAS event page](https://www.cmas.org/freediving-events/2025-cmas-world-championship-freediving-indoor.html) links the Microplus timing application. For a bounded DNF Masters Men result view, `freediving.cmas-2025-indoor-json` retains the exact `CGR1` response bytes, all source headers and rows, and the generated [HTML result page](https://results.microplustimingservices.com/CMAS/Results/#/2/dynamic-result-json/MAM/011/007/001) as the human-facing citation. The JSON endpoint remains a distinct acquisition URL. The parser checks the page route against the JSON category, competition, round, heat, sport and source filename before deriving an immutable schema-5 artifact. Invalid UTF-8, changed result structure and mismatched provenance fail closed.

The example response has 30 rows. Each preserves its source `PlaCod`, heat, lane, name, representation, category, `MemPrest` and `MemPoint` tokens. The raw row remains intact. This parser does not assign an athlete identity, interpret `PlaCod` as a globally unique person key, combine Results and Summary views, or approve a sporting attempt. Every candidate is unreviewed and blocked from selection. A known `PlaCod` collision in another retained 2025 view prevents global uniqueness assumptions. Other 2025 JSON views and the unavailable configured PDFs remain separate source gaps in [issue #8](https://github.com/jamiepratt/freediving-results/issues/8).

Private candidate packets label schema-5 observations as JSON and anchor each to its zero-based source row and the HTML result page URL.

Two private extraction versions preserve a pre-publication source-name correction: `/1` retained given-name-first text, while `/2` follows the generated HTML's surname-first display. Both versions replay and exact retries skip. The current `/2` artifact SHA-256 is `cc187f24c0eb156e4a05174acf915cb40bfcf43682a0dfd1f459419351557e06`.
