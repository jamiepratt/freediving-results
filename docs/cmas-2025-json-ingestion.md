# 2025 CMAS indoor JSON result ingestion

The 2025 Athens [CMAS event page](https://www.cmas.org/freediving-events/2025-cmas-world-championship-freediving-indoor.html) links the Microplus timing application. The source archive retains exact `CGR1` response bytes and cites the generated HTML result pages for Static Apnea (STA), Speed Apnea 8x50, DNF, Dynamic Apnea Bi Fins (DYNBF), and Dynamic Apnea (DYN), each across six junior, senior and master women and men categories. The [STA Masters Men page](https://results.microplustimingservices.com/CMAS/Results/#/1/static-result-json/MAM/001/007/001), [Speed Apnea Masters Men page](https://results.microplustimingservices.com/CMAS/Results/#/1/speed-result-json/MAM/004/007/001), [DNF Masters Men page](https://results.microplustimingservices.com/CMAS/Results/#/2/dynamic-result-json/MAM/011/007/001), [DYNBF Masters Men page](https://results.microplustimingservices.com/CMAS/Results/#/2/dynamic-result-json/MAM/016/007/001), and [DYN Masters Men page](https://results.microplustimingservices.com/CMAS/Results/#/2/dynamic-result-json/MAM/026/007/001) are examples. `freediving.cmas-2025-indoor-json` parses valid UTF-8 responses into source headers and rows. The JSON endpoint remains a distinct acquisition URL. The parser binds the page route to the JSON category, competition, round, heat, sport and filename. Version `/7` checks Speed Apnea against May 22, STA against May 23, DNF against May 20, DYNBF against May 21, and DYN against May 24, 2025. Speed, STA, DYNBF and DYN require round `007` and heat `001`. Earlier parser versions remain replayable. Invalid UTF-8, changed result structure and mismatched provenance fail closed.

The DNF Masters Men example response has 30 rows. Each preserves its source `PlaCod`, heat, lane, name, representation, category, `MemPrest` and `MemPoint` tokens. The raw row remains intact. This parser does not assign an athlete identity, interpret `PlaCod` as a globally unique person key, combine Results and Summary views, or approve a sporting attempt. Every candidate is unreviewed and blocked from selection. A known `PlaCod` collision in another retained 2025 view prevents global uniqueness assumptions. The B24 Seniors Women DNF response contains an invalid UTF-8 byte; the exact archived source and byte span permit only its one malformed row to remain explicitly unparsed. Other invalid bytes fail strict decoding. Other 2025 JSON views and the unavailable configured PDFs remain separate source gaps in [issue #8](https://github.com/jamiepratt/freediving-results/issues/8).

Private candidate packets label schema-5 observations as JSON and anchor each to its zero-based source row and the HTML result page URL.
