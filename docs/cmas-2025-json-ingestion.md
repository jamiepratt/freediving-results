# 2025 CMAS indoor JSON result ingestion

The 2025 Athens [CMAS event page](https://www.cmas.org/freediving-events/2025-cmas-world-championship-freediving-indoor.html) links the Microplus timing application. The source archive can retain exact `CGR1` response bytes and the generated HTML result page for each of the six DNF categories (junior, senior and master women and men). The [Masters Men page](https://results.microplustimingservices.com/CMAS/Results/#/2/dynamic-result-json/MAM/011/007/001) is one example. `freediving.cmas-2025-indoor-json` parses valid UTF-8 responses into source headers and rows. The JSON endpoint remains a distinct acquisition URL. The parser binds the page route to the JSON category, competition, round, heat, sport and filename, and checks the DNF discipline and May 20, 2025 event date before deriving an immutable schema-5 artifact. Invalid UTF-8, changed result structure and mismatched provenance fail closed.

The Masters Men example response has 30 rows. Each preserves its source `PlaCod`, heat, lane, name, representation, category, `MemPrest` and `MemPoint` tokens. The raw row remains intact. This parser does not assign an athlete identity, interpret `PlaCod` as a globally unique person key, combine Results and Summary views, or approve a sporting attempt. Every candidate is unreviewed and blocked from selection. A known `PlaCod` collision in another retained 2025 view prevents global uniqueness assumptions. One retained Seniors Women response contains an invalid UTF-8 byte; strict extraction rejects that full response pending a separately reviewed row-isolation method. Other 2025 JSON views and the unavailable configured PDFs remain separate source gaps in [issue #8](https://github.com/jamiepratt/freediving-results/issues/8).

Private candidate packets label schema-5 observations as JSON and anchor each to its zero-based source row and the HTML result page URL.

Both versions replay and exact retries skip. The current `/2` artifact SHA-256 is `cc187f24c0eb156e4a05174acf915cb40bfcf43682a0dfd1f459419351557e06`. Every `/2` raw row and row coordinate reconciled to the source; replay passed for both versions. The database backup SHA-256 is `a4050c828add8949221e7963775149a20675660fbf04b8bba663a796fd1d2c0c`.
